The OAuth2 service allows you to use your Appwrite project as a standards-based OAuth2 and OpenID Connect identity provider. Third-party apps can request access to your project's resources through the standard authorization code flow, device authorization flow, and pushed authorization requests (PAR).

Users approve or reject authorization requests, and approved grants can be listed, inspected, and revoked at any time, giving you complete control over which apps hold access and for how long.

The service issues and refreshes standards-compliant access tokens, and exposes endpoints to list the organizations and projects an authorized token can access.
